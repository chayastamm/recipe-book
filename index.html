Importing recipes from a PDF

The Import button reads a .json file. The easiest way to turn a PDF cookbook into one is with an AI assistant.

  1. Open an AI assistant that accepts file uploads, such as Claude.
  2. Attach your PDF, then paste this prompt and send it: 
    Extract every recipe from the attached PDF into JSON. Reply with only the JSON, no other text, in exactly this format:

{"recipes":[{"title":"...","category":"...","ingredients":["one ingredient per item"],"steps":["one step per item"],"notes":"tips, serving notes, and the source if one is given"}]}

Use the cookbook's section headings as the category. Keep quantities and wording exactly as written. Don't add anything that isn't in the PDF.
  3. Copy the JSON from the reply. Open Notepad, paste it, and choose File → Save as. Set Save as type to All files, Encoding to UTF-8, and name it something like my-recipes.json.
  4. Click Import and choose the file.

Tips

  • For a big cookbook, ask for a few pages at a time (for example, "pages 1–30 only") and import each file. Recipes already in your book are skipped, so nothing gets duplicated.
  • Photos in the PDF aren't imported. Add them afterwards with Edit.
  • Spot-check a few recipes after importing and fix anything with Edit.
